## 二、美国方案详解

### 1. ⭐ Tello — 综合推荐，无限短信

| 项目 | 内容 |
|------|------|
| **运营商** | Tello Mobile (T-Mobile MVNO)，总部亚特兰大 |
| **号码类型** | 美国实体移动号码 (Wireless)，非VOIP，Carrier: T-Mobile |
| **套餐内容** | $5/月：100分钟国际通话 + **无限短信** + 无数据 |
| **内地使用方式** | 必须通过 **WiFi Calling**（需先填E911美国地址） |
| **收短信** | WiFi Calling 下**免费且无限** |
| **发短信** | WiFi Calling 下**免费且无限** |
| **打电话** | WiFi Calling 下100分钟免费拨打60+国家（含中国）；超出$0.49/分钟 |
| **数据流量** | 不支持中国漫游数据；可购流量包$0.02/MB（极贵，不推荐） |
| **保号要求** | 每月$5自动续费；手动续费可用Tello Dollars免税费；取消套餐后号码立即失效 |
| **特色功能** | 支持携号转入Google Voice（$20一次性→永久免费） |
| **支付方式** | Visa/MasterCard/Amex/PayPal（国内全币种卡可）；填中国大陆地址0税费 |
| **开通要求** | 无需实名；eSIM激活需要**美国IP**；需填E911真实美国地址开WiFi Calling |

**获取流程：**
1. 用推荐链接注册（赠送$10 Tello Dollars）
2. 选择 $5 No Data + 100 Min 套餐
3. 账单地址填中国大陆（免税）或美国免税州（Idaho等）
4. 选择 eSIM 并填写 IMEI
5. 付款下单（首次约$5）
6. 在 My Settings 填 E911 地址 → 开 WiFi Calling
7. 用美国IP扫描二维码激活 eSIM

**推荐人群：** 需要无限免费收短信，偶尔打国际电话，eSIM用户

### 2. ⭐ Ultra Mobile PayGo — 最便宜的美国实体卡

| 项目 | 内容 |
|------|------|
| **运营商** | Ultra Mobile (T-Mobile MVNO)，2019年从T-Mobile接手PayGo业务 |
| **号码类型** | 美国实体移动号码，Carrier: T-Mobile |
| **套餐内容** | $3/月：100分钟通话 + 100条短信 + 100MB（仅美国内） |
| **内地使用方式** | 两种：①WiFi Calling ②直连中国移动漫游 |
| **收短信(漫游)** | $0.1/条；WiFi Calling $0.01/条(套餐100条免费) |
| **发短信(漫游)** | $0.5/条；WiFi Calling $0.01/条(套餐100条免费) |
| **打电话(漫游)** | $3.59/分钟；WiFi Calling $0.03/分钟(套餐100分钟免费) |
| **漫游网络** | **中国移动**（直连，无需WiFi Calling也能收短信！） |
| **保号要求** | 余额不足月租超**90天**则销号；最小充值$5 |
| **WiFi Calling问题** | ⚠️ 2022.10起部分IP被墙，需要特殊解决 |
| **eSIM** | 需先买实体卡激活后转eSIM；每年免费转2次，之后$3/次 |
| **开通要求** | 无需实名；eBay购买（仅寄美国地址）；45天内激活；必须通过转入号码方式激活（不可直接漫游激活） |

**获取流程：**
1. 从 Ultra Mobile 官方 eBay店 购买 ($13)，需美国收货地址
2. 或从 T-Mobile 部分线下店购买 PayGo专用卡
3. 激活时选择"转入已有号码"（如Google Voice号码）
4. 充值时用免税州邮编（推荐OR州，除Portland外，综合税率最低-4.8%）

**推荐人群：** 极致低成本，能接受WiFi Calling折腾

### 4. 🔹 Google Voice ⚠️ — 免费的虚拟号码

| 项目 | 内容 |
|------|------|
| **成本** | **完全免费** |
| **号码类型** | VoIP虚拟号码（非实体移动号） |

## 三、英国方案详解

### 1. ⭐ giffgaff — 英国保号王者

| 项目 | 内容 |
|------|------|
| **运营商** | giffgaff (O2 MVNO)，英国最流行的虚拟运营商 |
| **号码类型** | 英国实体移动号码 +44 |
| **内地使用方式** | 插卡直接漫游中国联通收短信 |
| **收短信** | **免费** |
| **发短信** | £0.30/条 |
| **打电话** | £1/分钟 |
| **数据** | £0.20/MB（务必关闭数据漫游！） |
| **保号要求** | 每**180天**至少有一次付费活动（建议每3个月发一条短信） |
| **年保号成本** | 发4条短信/年 = £1.20 ≈ 约11元人民币 |
| **eSIM** | ✅ 官方App直接申请 |
| **开通要求** | 无需实名！但官方已停止邮寄中国，需通过国内现货或eSIM |

**获取流程：**
1. 手机支持eSIM → 下载giffgaff App，直接注册开eSIM（最干净方案）
2. 需要实体卡 → 京东/拼多多 搜索"英国信封"购买未激活卡
3. ⚠️ 只买**未激活**卡，不要买已激活附账号的
4. 首充£10（用充值券或信用卡），激活后测试收短信

**保号操作：** 在手机日历设提醒，每3个月发一条短信（到任意英国号码或自己的国内号）

**推荐人群：** 需要英国号码，低维护成本，适合大多数场景

## 四、德国方案详解

### 1. 🔹 沃达丰德国 CallYa — 近乎免费的欧洲号

| 项目 | 内容 |
|------|------|
| **运营商** | Vodafone Germany（欧洲顶级运营商） |
| **号码类型** | 德国实体移动号码 +49 |
| **开卡费用** | **0元**（完全免费申请eSIM） |
| **保号要求** | 每**90天**有一次余额变动（充值或消费） |
| **年保号成本** | 配合Wise自动转账0.01€/月 = **€0.12/年 ≈ 不到1元人民币！** |
| **内地使用方式** | 漫游中国联通收短信 |
| **收短信** | **免费** |
| **发短信** | €0.29/条 |
| **eSIM** | ✅ 原生eSIM |
| **开通要求** | ⚠️ **需要护照视频实名认证(KYC)**；需要德国纯净住宅IP；身份证不行 |

**获取流程：**
1. 访问Vodafone DE CallYa申请页
2. 填写德国真实地址（Google Maps找）
3. 下载POSTIDENT App，进行护照视频认证
4. 通过后收到eSIM PDF（含二维码和ePIN）
5. 扫描二维码下载eSIM到手机
6. 用Wise设置每月自动转0.01€保号

**难点提醒：** 近期风控升级，需要德国纯净住宅IP才能进入人脸验证。KYC全程德文，门槛较高。

**推荐人群：** 愿意折腾，想近乎0成本持有欧洲顶级运营商号码

### 一个重要提醒

**任何真正重要的账号，不要只依赖一张卡**。所有运营商的保号政策都可能随时变更。建议：
- 重要账号绑定1张主力卡 + 1张备用卡
- 在日历设置定期提醒做保号操作
- 保留账户登录凭证（邮箱、密码、PIN码等）比保留SIM卡本身更重要
