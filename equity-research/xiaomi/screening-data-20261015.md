1. **本次采集使用了 `general-purpose` 子代理并行执行**，每个子代理约 150–180k token、5–10 分钟。提示词中的关键纪律（**"未获取到必须明说"、"绝对不要用记忆或估算填空"、"每项给出数字+来源URL+日期"**）效果良好——子代理主动标注了 3 处未获取到，未出现编造。
2. **行情数据用腾讯接口直取**（`https://qt.gtimg.cn/q=hk01810`，GBK 编码），比 yfinance 稳定（Yahoo API 直连被 reset）。格式见 `handoff.md` 附录 A。
3. **PDF 全文靠 `tvly extract` 转换**，公司 CDN 与雪球 PDF 直连均被 TLS reset。
4. **`dcf.py` 与 `check_research_output.py` 只用 Python 标准库**，无需安装依赖（系统 Python 3.13.5 受 PEP 668 保护，`pip install` 会失败）。
